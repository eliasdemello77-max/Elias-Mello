# OZ Tecnologia

Sistema inteligente de gestão de frotas, abastecimento, telemetria e operações logísticas.

## Projeto

Plataforma de tecnologia voltada à gestão operacional de transportadoras, com foco em eficiência, controle, segurança e inteligência de dados.

## Tecnologias

- GitHub: versionamento do código
- Supabase: banco de dados, autenticação e arquivos
- Vercel: hospedagem e publicação

## Objetivo

Transformar a gestão de transportes por meio da tecnologia, inteligência e propósito.
